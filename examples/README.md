## GETTING STARTED

- `linux_windows_example/` — A standalone PH8 interpreter for Linux and Windows (Cygwin).
- `amalgamated/` — A standalone PH8 interpreter for Linux and Windows (Cygwin), built from a single amalgamated source file. This allows the compiler to perform more aggressive optimizations.
- `http_server/` — A standalone HTTP server for serving static files and executing `.php` scripts. Supports Linux and Windows (Cygwin).

## ARDUINO EXAMPLE

- `arduino_simple/` — An example project for the Arduino IDE, demonstrating how execute .php script from memory buffer
- `arduino_example/` — An example project for the Arduino IDE, demonstrating how to execute .php scripts from a TAR filesystem 

## DIGGING DEEPER

- `api_examples/` — A collection of examples demonstrating how to use the PH8 C API from your own C applications.
- `test_files/` — A collection of small `.php` scripts used to test various language features and extensions. Run these scripts using the PH8 interpreter built from either `amalgamated/` or `linux_windows_example/`.
