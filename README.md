### PH8 : A further development of PH7 PHP Engine. 


**Comparision: PH8 vs ZendPHP**: [current status](https://github.com/vvb333007/PH7-ESP32/docs/Language.md)
**Сравнение PH8 и ZendPHP**: [состояние дел](https://github.com/vvb333007/PH7-ESP32/docs/Language.md)

**Work in progress** [A roadmap](https://github.com/vvb333007/PH7-ESP32/blob/master/TODO.md)

Compiles and runs on ESP32-family, Linux and Windows (Cygwin).
Memory footprint: requires about 100KiB of memory for the Engine plus ~180 KiB per virtual machine;
Running PH8 without external RAM is barely possible. Modern ESP32 chips are all equipped with plenty of PSRAM (4..8MiB)
